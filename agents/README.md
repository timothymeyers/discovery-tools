# Agents

Custom agents for Microsoft Discovery, as `*.agent.md` files.

Nothing here yet.

When the first agent lands, add `"agents": "agents/"` to the root `plugin.json` so it ships
with the plugin. Note that there is no `gh agent install` — bundling into the plugin is the
only native cross-repo install path for custom agents.

Frontmatter reference:
<https://docs.github.com/en/copilot/reference/custom-agents-configuration>
